# 图案、指甲与毛发

## 从原 UV 转到新 UV

读取 blend，确认原模型、新身体/衣服、材质槽、活动 UV 和世界变换。不要假定两张平面贴图上的相似区域对应同一身体部位。

1. 分离源图中的纹身/图案，产出独立的灰度遮罩或透明覆盖层。剔除指甲、阴影、衣服底纹等误选内容。裁切修复图案时保留原比例与定位参照。
2. 在相同世界坐标下建立源网格 BVH；逐目标 UV 三角形光栅化，利用重心坐标算表面点，再找源三角形及其 UV，双线性采样图案遮罩。
3. 限制身体部位、距离和法线方向，避免最近点投到另一条腿、身体背面或重叠衣片。最近点不可靠时按已确定方向射线投影；记录未覆盖像素，不用镜像猜补。
4. 纹身按透明颜料与目标底色合成，保留新底色的皮肤明暗。淡化时降低覆盖层权重，而不是模糊整张底图。
5. 给接缝增加 UV padding。检查正面、背面、两侧和跨缝部位，必要时补断线和错位。不要把图像坐标从上向下与 Blender UV 从下向上混淆。

锐化/补全应针对线稿或遮罩；不要同时锐化皮肤噪点。图案清晰度受目标 UV 密度限制，4K 输出不能创造缺失的源细节。

## 粉蓝指甲

颜色只覆盖实际甲面，检查两脚全部脚趾。甲根、甲侧沟和游离缘属于外观的一部分；甲面有颜色不代表指甲已完成。

- 甲面用连续粉/蓝渐变；颜色取自角色现有头发时先采样，不凭印象取色。
- 分开保存甲面遮罩、甲根/侧沟遮罩与修饰区域总遮罩。
- 微弱凸面、根部与侧沟用高度微分生成法线。按目标网格 TBN 转换，并确认切线手性及 DirectX/OpenGL 的 Y 方向。
- 只在甲面降低粗糙度，沟边保持皮肤感。Celeste 示例甲面约 0.18、沟边更粗糙，这些不是其他角色的固定数值。
- 无纹身变体从干净底色生成，然后复制同一份指甲修饰区域，防止纹身残留或两版指甲不一致。

## 有纤维感的局部毛发

先生成/绘制独立透明图案，再定位到身体表面。保留可重烘焙的遮罩、图案和区域坐标，避免直接覆盖不可回退的底图。

- 边缘使用稀疏、渐细且方向连贯的毛丝；纯粹高斯模糊硬轮廓不能替代纤维感。避免整齐的贴纸式边线。
- 像素级毛丝高度先去低频底色，提取细小纹理，再沿表面转换为切线法线；不能把 RGB 当法线。
- 毛发、皮肤、指甲的粗糙度独立。通过分区遮罩确认区域外的颜色、法线、粗糙度未变化。
- 所有变体共享法线/粗糙度，只在纹身底色上分叉；若衣服透明设置不同，另在材质阶段分叉。

## 通道注意事项

BaseColor 通常使用 sRGB；遮罩、金属度、粗糙度和法线使用数值/非颜色语义。Blender 的浮点像素、PNG 字节与编译器通道解释必须实测一致。

不要猜 Source 2 编译后的 alpha 用途。同一着色器在不透明和半透明组合下可能把颜色 alpha 分别用于金属度或透明度；法线纹理也可能打包粗糙度。反编译输出通道验证，允许 BC 压缩产生小误差。
